# Movie-Recommender
🎬 Movie Recommender System
This is a simple yet effective Content-Based Movie Recommender System built using Python and Streamlit. The system suggests movies based on the similarity of content such as genre, overview, cast, and keywords. It's perfect for anyone looking to explore new movies similar to their favorites.

🔍 Features
Content-based filtering using cosine similarity
Instant movie recommendations based on user input
Movie posters fetched dynamically using TMDb API
Deployed as a user-friendly web app using Streamlit

🛠 Tech Stack
Python 
Pandas & NumPy for data processing
Scikit-learn for similarity calculation
Pickle for model serialization
Streamlit for the interactive UI
TMDb API for fetching poster images

⚠️ Note
Due to TMDb being blocked in India, I cannot deploy the app publicly right now. However, the app runs perfectly on localhost, and you can access full functionality including movie posters by using a VPN while running it locally.
